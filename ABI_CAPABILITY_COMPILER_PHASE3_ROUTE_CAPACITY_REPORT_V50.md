# Phase 3 routed full-generator capacity result

Status date: 2026-08-07

V50 is complete and failed. It was a permanently non-promotional upper-bound
control: all 4,174,280 parameters in the existing generator topology could
adapt while the qualified V45 router, 7,000-record acquisition IR,
representation, and locked development gates remained fixed.

The candidate scored 785/1,400 (56.07%), produced 36 repetition collapses, and
trailed the teacher by 32.29 percentage points; the paired 95% interval was
[-34.57, -30.00] points. Routing remained 1,400/1,400 and generation produced
no runtime errors. Exact inspection confirmed that all 1,400 deployed control
prefixes encoded to the same token sequences used during training, so the
cross-route emissions are not caused by a training/evaluation encoding split.

The preregistered V51 read-only attribution then measured 96.53% teacher-forced
action accuracy and 79.14% exact sequences on the 7,000 acquisition records,
below the locked 99% and 90% fit gates. The weakest exact-sequence strata were
email drafting (45.0%), tone control (48.4%), clarification (53.0%), and
conversation (56.2%).

This closes the current router/data/representation/generator-topology
combination as optimization or fit limited. It does not prove a fundamental
ABI or LayerCake ceiling, does not authorize a nearby hyperparameter sweep,
does not certify Phase 3, and does not open Phase 4. Phase 2 also remains
blocked on 21,000 external human judgments.
