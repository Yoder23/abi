# R81 protocol: prospective corrected-source replication

R80 failed its preregistered raw source family floor. Its one authorized
post-failure diagnostic found that subtracting the same candidate's score in a
same-list, no-relation prompt yielded 1,369/1,400 and cleared every family
floor. R80 remains failed and non-promotional.

R81 is a clean prospective test of that exact, frozen correction. Its 1,400
validation-only prompts use new lexical triples, a new subject prefix, a new
nonce range, and no exact prompt or lexical-stem overlap with R76, R77, or R80.
The catalog is sealed before any R81 source or candidate scoring.

For every candidate, the scorer computes mean token log probability under the
actual relation prompt and under one fixed neutral prompt containing the same
three candidates in the same display order. The only decision score is actual
minus neutral mean log probability. There is no fitted coefficient, threshold,
family adjustment, or post-result retry. Raw source selection is retained as a
descriptive control.

The pinned source passes only with at least 1,330/1,400 corrected selections,
at least 180/200 in every premise family, and zero corrected-score ties. Source
failure blocks R79 host training. Source success authorizes exactly the
preregistered R79 prompt-identity bridge run; it does not certify unrestricted
reasoning, English transfer, domain transfer, minimization, or the ABI moonshot.
