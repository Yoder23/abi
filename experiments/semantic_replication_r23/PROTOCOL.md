# R23 fresh semantic-contract replication

R21 remains failed under its frozen lexical scorer, and R22 remains a failed
teacher-normalization prerequisite. Neither result is rescored or promoted.

R23 tests the narrower diagnostic hypothesis that the exact frozen R21
packages preserve supplied-data meaning on a new hidden split even when they
use public-corpus-supported paraphrases. Its task-aware semantic contract is
committed before a new 256-bit row seed is generated. The seed commitment is
committed before reveal. The source then produces 120 fresh comparison rows,
and the unchanged R21 package bytes execute without student training.

The semantic contract changes only summary field scoring. It requires every
prompt number to appear, rejects every number absent from the prompt, and
requires public-corpus-supported concepts for sensor stability, latency
decrease, and scheduled review. Format, fluency, hallucination, collapse, and
all other task rules remain the R21 rules.

The replication passes only if:

- the frozen registered labeler is exact on 120/120 new instructions;
- every factorized seed passes at least 18/20 rows in every task;
- every factorized seed is 120/120 non-hallucinating and non-collapsed;
- every factorized seed is no worse than the live teacher and both frozen
  matched controls;
- all 24 signed package files are byte-identical to the R21 public candidate;
- 1,080 GPU and 54 task-covering CPU rows execute; and
- the source teacher is absent during package execution.

No retraining, package edit, scorer edit, instruction edit, row deletion,
threshold change, second reveal, or evaluation-driven retry is authorized.
Passing certifies only the bounded six-task supplied-content mechanism under
the semantic contract. It does not certify general English, autonomous
ontology discovery, arbitrary domains, global minimality, LoRA/distillation
superiority, or the full ABI moonshot.
