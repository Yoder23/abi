# R30 broad English-substrate public falsification

R30 tests whether ABI can acquire a materially broader, fact-quarantined
English realization substrate from the frozen Qwen2-7B-Instruct source and
execute it as independently signed LayerCake packages with the teacher absent.

The public pilot contains twelve behaviors: prose, summarization, rewriting,
email drafting, bullets, tone control, clarification, conversation, planning,
comparison, domain-independent reasoning, and abstention. Prompts contain
synthetic supplied context and unique nonce identifiers rather than factual
answers. The source is asked to name each capability without being given a
label menu. A generic normalizer maps lexical variants to package tags; rows
that cannot be normalized are quarantined.

The experiment is a falsification prerequisite, not a certification. It must
record every source row, label, package, output, and information cost. It may
not claim unrestricted English, global minimality, domain-discovery
completeness, human parity, or superiority to LoRA/distillation. A passing
pilot only authorizes a separately frozen fresh replication and a registered
minimum-information comparison.
