# R10 end-to-end capability copy/paste protocol

R10 connects two results that were previously separate: R8's synthetic
source-learning/extraction event and R7-style frozen-host capability execution.
It tests ABI-C4 in the proof ledger. It does not test native neural
transplantation.

## Registered claim

For the opaque modular micro-language only, one source-trained transition state
is extracted into an immutable canonical package. The same package bytes are
pasted into three pinned frozen recipients. A fixed, zero-parameter,
capability-blind canonical interpreter executes the package and a host codec
realizes its output through recipient logits. No recipient parameters are
trained or mutated.

The generic codec derives one native output token per canonical digit only when
that token's isolated decode is byte-exact to the digit. This handles tokenizer
segmentation without embedding any tokenizer identity or token map in the
capability package.

This is **runtime-owned copy/paste execution**. The interpreter parses the
registered grammar and computes the package semantics. Therefore a pass must
not be called recipient internalization, tensor transplantation, native neural
transfer, English extraction, or teacher-quality knowledge transfer.

## Public matrix

- Four public R8 development capabilities.
- 512 distinct rows per capability at depths 4-7.
- Pythia-160M, Qwen2.5-0.5B, and T5-base at the exact R8 revisions.
- Conditions: BASE, AFTER, BEFORE, WRONG, ZERO, RANDOM, SHUFFLED, REMOVED,
  INTERPRETER_REMOVED, and RESTORED.
- One content-addressed AFTER package per capability and one shared BEFORE
  package. Package files contain no prompts, answers, row IDs, executable
  solver, tokenizer identity, host identity, hidden width, or host matrix.

## Pass gates

- The live source AFTER condition is at least 0.99 and improves by at least
  0.70 over source BEFORE for every capability.
- AFTER and RESTORED are exactly 1.0 on every recipient and capability.
- AFTER and RESTORED predictions are byte-identical for every paired row.
- BEFORE, WRONG, ZERO, RANDOM, and SHUFFLED are each at most 0.30.
- REMOVED and INTERPRETER_REMOVED exactly equal BASE row by row.
- One package SHA-256 is identical across every recipient invocation.
- Recipient model state is byte-identical before and after; recipient optimizer
  steps and interpreter learned parameters are zero.
- Source execution completes before recipient execution and the source object
  is not loaded by the recipient path. Physical source-file absence is not
  claimed on this host.
- Raw rows, packages, receipts, code hashes, and metrics recompute fail closed.

## Stronger claims that remain closed

Even a perfect result does not open native neural transplantation, arbitrary
teacher extraction, semantic labeling, English/domain quality, information
minimality, LoRA/distillation superiority, human quality, or the full ABI
moonshot.
