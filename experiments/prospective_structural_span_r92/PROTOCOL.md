# R92 preregistration: prospective structural-span certification

R91 passed its disclosed development gate at 95/100 after the R90 structural
shortcut failure. R92 is the single prospective test authorized by that pass.
The R91 checkpoint, metadata, R76 LayerCake host, imported ABI artifact,
architecture, decoding, evaluator, random control, and gates are frozen before
the R92 catalog is materialized.

The catalog contains 1,400 prompt-unique two-hop nonce-reasoning rows: 200 for
each of seven relation-language families withheld from R91's 16 training
forms. It also uses five new outer interfaces, four candidate-list placements
including list absence, unseen lexical triples, a new subject prefix, and
seven-digit identities outside training and R60/R88/R89 validation. Semantic
role stems and candidate display positions rotate independently.

Execution order is fail closed:

1. Commit this protocol, builder, verifier, source wrapper, screen, and binding
   code without a catalog or source/candidate observations.
2. Materialize and hash the catalog, verify its coverage and disjointness, then
   commit the immutable catalog and its exact hash into the source wrapper.
3. Score the pinned unchanged Phi-3 source on GPU. Source code imports no R91
   module and records `candidate_accessed=false`.
4. Bind the already frozen R91 candidate, source rows/result, catalog, and all
   implementation files; commit that binding before candidate execution.
5. Execute R91 and a fresh deterministic random bridge through the unchanged
   sparse LayerCake host on every row.
6. Strictly recompute all claims from raw rows and run hostile mutations.

The source authorization gate requires at least 1,330/1,400 prior-corrected
selections, all candidate display positions represented, and zero corrected
ties. Family counts are diagnostic because a source-family floor is not a
candidate transfer prerequisite.

The R91 package passes only if it reaches at least 1,330/1,400, at least
180/200 in every family, retains at least 95% of source-passing rows, gains at
least 50 percentage points over the unchanged parent, beats the random bridge
by at least 50 points, the random bridge passes at most 500 rows, collapse is
zero, every row physically executes one reasoning cake plus six deep adapters
plus one bridge, the teacher is absent, and every bound artifact is unchanged.

A pass certifies only this bounded prospective reasoning-capability transfer.
It does not certify broad fluent English, arbitrary domains, global
minimality, LoRA/distillation superiority, human preference, independent
hardware, or the full ABI moonshot.
