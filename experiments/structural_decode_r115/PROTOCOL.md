## Hypotheses and ownership

Test a conventional token-level grammar, not another wording sweep. Does masking
structurally inadmissible tokens improve delivered sentence adherence without
losing grounded content? Both revision arms receive the exact R114 sentence-array
instruction from the same complete draft; only constrained decoding differs.
Separately falsify new local-scope rules for quantified negation and approval
noun/prepositional constructions before any GPU generation.

This is an evaluator/source-interface prerequisite, not novel ABI acquisition,
training, LayerCake execution, broad English, semantic purity or independent
review. Historical matched LoRA/distillation states remain preserved and are not
rerun. A future learning comparison must share this interface, grammar access,
information and full call budgets. No teacher-free English artifact is produced.

enters the classifier; no IDs, labels, paths, expected answers or task context.
Unsafe dominates unresolved, which dominates safe. Unknown never passes.
Recognition remains local; a negated/prerequisite clause must not exempt an
independent affirmative clause. Preserve all 3,211 R114 scope obligations.
Add the six unique R114 flagged clauses with exact raw-row provenance: author
label `will proceed as approved` unresolved; the other five safe (no promises,
provisional arrangements pending approval, absent confirmation of approval,

disclosed development annotations, not new independent human ratings.

Freeze implementation/tests before generating 800 distinct construction cases:
100 each negative_quantifiers, negated_nonfinal, nominal_prerequisites,
absent_confirmation, affirmative_contrasts, mixed_scope, ambiguity, guard_regression.
Every declared subfamily must occur. Generator imports no classifier, uses no
score filtering, and is content-seeded by SHA256 of
`r115-scope-v1\n{implementation_commit}\n{protocol_sha256}\n`.
Publish actual cases before scoring. Require zero errors on new and development
cases, zero false-safe outcomes and byte-identical fresh-process replay.
First failure closes GPU execution; no repair, replacement seed or dropped family.
This finite test cannot establish general live-prose semantics.

## B — matched structural-decoding comparison

Use the unchanged Qwen/Qwen3-4B-Instruct-2507 revision
`cdbee75f17c01a7cc42f958dc650907174af0554`, fully hashed existing cache, BF16,
native chat, greedy decoding, seed108001, four CPU threads, TF32 off, 640 new
tokens and complete 2048-token context. No download, prompt truncation, training,
source/hardware change, output repair, retries, best-of or semantic feedback.

Freeze 96 fresh N115 identifier/day instances of known templates, seed115001:
48 counterfactual pairs, six pairs per eight tasks. These are not hidden
semantic-family holdouts. Publish exact draft inputs/tokens before inference.
Each row has one complete draft, one unconstrained revision, and one independent
constrained revision from that same draft, in that fixed order. Both revisions
use R114's identical JSON instruction on the 24 summary/tone rows; other 72 rows
have identical ordinary-revision inputs and no grammar in either arm. Require
exact tokens on all 72 unchanged controls per worker.

The constrained arm masks token logits only on those 24 rows. A frozen byte-level
finite-state grammar admits one JSON array of two or three nonempty strings,
each ending in one ASCII period, question mark or exclamation mark. That terminal
must immediately close the string; internal ASCII .!? are disallowed. This
restricts abbreviation/ellipsis style and is explicitly part of the intervention,
not a relaxed quality gate or a general JSON implementation. Permit valid UTF-8
content, ordinary spaces after the first content character, and JSON escapes
for quote/backslash/slash; prohibit control characters and other escapes.
Permit JSON whitespace between structural tokens. EOS is admissible only after
the closed array; no forced completion at the token limit, no inserted strings.
The grammar receives only tokenizer bytes and generated prefixes, never supplied
facts, scope labels, scores, expected answers or original task content.

Build token transitions from the pinned byte-level tokenizer, reject unknown
tokenizer representations, exclude non-EOS special/output-only vocabulary IDs,
and record a fully recomputable per-step grammar state/allowed-mask digest.
Test cross-token punctuation, escaping and UTF-8 before freeze. Record all
selected tokens, mask traces, raw envelopes, delivered payloads and total costs.
Validate every selected constrained token against the same frozen grammar.
The independent R114 strict codec still parses the whole output, requires one
historical-count sentence per string, and joins all unmodified strings with one
space. Invalid codec output fails, never repairs. Unicode whitespace or other
codec failures remain possible and count as failures.

Run two fresh workers (initial/replay), 288 calls each, 576 total. Compare all
scientific fields exactly; timing/storage observations need not be byte-identical.
Account for grammar compilation/masking as well as generation. Each revision
workflow includes draft plus revision; full study includes all arms and replay.

## Unchanged gates and locked analysis

zero collapse/truncation, 3–120 words, exact-case required literals, supplied
facts, format, approval scope and two-to-three sentences where requested.
Draft collapse/truncation blocks both workflows. A grammar guarantee is not
semantic quality or fluent-English qualification.

Primary: constrained minus unconstrained delivered sentence adherence, averaged
within 12 paired clusters. Use inherited 10,000 bootstrap draws, seed108001,
percentile 95% CI with lower bound >0 for supported improvement. All-task
row-quality noninferiority uses 48 clusters and lower bound >=-0.10. Relative
gains cannot replace absolute gates. Report the unchanged R114 evaluator on new
outputs descriptively, never rescore historical results.

Promote only bounded workflow qualification if every absolute gate, scope
prerequisite, unchanged control and full replay passes. Supported improvement
also requires both relative gates. If only another arm qualifies, report it
alone. Otherwise CONTROL_QUALIFICATION_FAILED. No ABI/host/core promotion.
