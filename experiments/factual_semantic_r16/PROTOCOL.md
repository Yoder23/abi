# R16 preregistered factual acquisition and segregation protocol

## Question

Can ABI recover pre-existing factual knowledge from an unchanged open-weight
source, compile the source evidence into two immutable semantic packages in a
physical no-network capsule, and execute those packages on unseen paraphrases
with the source absent?

## Boundary

The held-out universe is frozen at 24 periodic-table atomic-number facts and 24
national-capital facts, all distinct from the R16 public-development facts. A
32-byte secret selects eight facts per namespace. The source receives three
answer-free extraction paraphrases and three disjoint evaluation paraphrases
per selected fact.

For extraction, the unchanged source generates an open answer and scores 12
registered candidate value sequences. The physical compiler receives only the
subject, natural-language question, candidate strings, and source scores. It
does not receive fact IDs, correct answers, oracle fields, namespace fields,
the secret/reveal, success IDs, evaluation rows, source model, or development
filesystem. Its generic registered ontology assigns chemistry versus geography
from question semantics, requires three-view value agreement, and emits one
canonical factual package per namespace.

The resulting packages are evaluated on three unseen paraphrases per fact.
Combined, namespace-only, cross-namespace, removal, and score-rotation controls
are all recomputed from raw rows.

## Exact gates

- 16 secret facts, eight per namespace;
- 48/48 extraction open generations exact;
- 48/48 source candidate-score selections exact;
- 48/48 semantic labels exact;
- two physically compiled packages with eight facts each;
- 48/48 combined-package unseen-paraphrase answers exact;
- 48/48 package/source normalized answers exact;
- each namespace-only package answers all 24 in-domain rows and abstains on all
  24 out-of-domain rows;
- package removal abstains on 48/48 rows;
- score-rotation control accuracy at or below 0.10;
- zero source training and no source in package execution;
- complete imported-information and runtime accounting; and
- fail-closed strict verification of all required files, hashes, counts, and
  recomputed claims.

## Claim ceiling

A pass proves only bounded, closed-candidate factual extraction and semantic
segregation for the registered chemistry/geography families. Candidate
vocabularies and the two-domain ontology are registered; this is not autonomous
open-world discovery. The packages are structured factual memory executed by a
generic runtime, not a fluent neural English substrate or production LayerCake
cake. It does not prove arbitrary-domain extraction, English transfer, global
minimality, independent hardware reproduction, or superiority to LoRA or
distillation.
