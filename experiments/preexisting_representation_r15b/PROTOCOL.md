# R15B preregistered pre-existing representation protocol

## Question

R15B asks whether ABI can recover a bounded capability already available in an
unchanged pretrained open-weight source, using internal representation access
instead of a source training delta, and emit the unchanged R11 package for
teacher-free execution on heterogeneous frozen recipients.

The registered path is:

```text
frozen Qwen2-7B-Instruct (zero training)
  -> six deterministic source generations per anonymous capability
  -> pre-answer final residuals + eight frozen digit output rows
  -> physical pivot-root/no-network generic decoder
  -> unchanged R11 package + separate semantic label manifest
  -> frozen Pythia, Qwen2, and T5 recipients (zero training)
```

## Public prerequisite

Public source screening preserved five unsuccessful interfaces before finding
the bounded source frontier. The teacher is exact on all 24 atomic arithmetic
rows through its normal generation path, exact on 32/32 depth-2 rows, and
28/32 at depth 4, but it does not sustain depth 8/12. Therefore Track A
teacher-behavior cloning is explicitly not a passing R15B claim.

The public representation preflight used six anchors only. It reconstructed
the source logits from pre-answer residuals and output rows to maximum absolute
error `1.1161773727508262e-08`, decoded the exact affine transition, emitted an
unchanged R11 package, scored 10,000/10,000 deep oracle rows, and kept all
controls at or below 0.2507.

## Held-out boundary

A cryptographic secret selects four distinct permutations of three registered
pre-existing arithmetic operations. The code, gates, public prerequisite, R11
boundary, source revision, recipients, isolation policy, data sizes, and
control interventions are frozen before reveal.

For each hidden permutation, Qwen receives two atomic prompts per anonymous
slot. ABI retains the final residual immediately before the generated answer
and the eight frozen source output rows. The physical extractor receives only
that anonymous tensor bundle, its generic specification, and pure-stdlib
decoder. It receives no prompt, answer, completion, capability ID, permutation,
semantic label, operation table, oracle, candidate search, source model, or
development tree. The old root and Windows mount are physically absent.

The separate semantic manifest binds the extracted package hash to the fixed
namespace `mathematics/modular-arithmetic/compositional-affine-mod8` and the
decoded slot labels. This is a registered ontology binding, not autonomous
open-world label discovery.

## Gates

- Four distinct secret slot permutations are required.
- The unmodified source must generate all 24 anchors exactly with zero training.
- Local and physically isolated decoders must agree on all six labels per
  capability with positive margins.
- Every unchanged R11 package must score 10,000/10,000 on prompt-disjoint
  depth-13--18 oracle rows.
- Wrong-capability, zero, random, residual-shuffle, and output-row-shuffle
  controls must each remain at or below 0.30.
- The identical package bytes must produce 1.0 AFTER and RESTORED behavior on
  Pythia, Qwen2, and T5 with zero recipient optimizer steps; registered
  negative conditions must stay at or below 0.30 and removals equal BASE.
- Source, bundle, capsule, package, label, codec, recipient, raw-row, manifest,
  configuration, and reveal identities must be hash-bound and recomputable.
- Missing or stale evidence fails closed. Stored scientific booleans are not
  accepted as proof.

## Claim ceiling

A pass establishes only
`BOUNDED_PREEXISTING_REPRESENTATION_CAPABILITY_RECOVERY`: a zero-parameter
generic decoder can convert a small internal representation bundle from an
unchanged pretrained source into an exact portable transition package under a
secret anonymous slot mapping.

It does not establish deep teacher-behavior cloning, arbitrary pretrained
knowledge extraction, English fluency transfer, autonomous domain discovery,
open-world semantic labeling, a minimal English substrate, production
LayerCake ingestion, or superiority to LoRA/distillation. Those gates remain
open.
