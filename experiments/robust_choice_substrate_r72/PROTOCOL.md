# R72 preregistration: robust conditional-choice reasoning substrate

R71 failed its aggregate gate, but identified one sharply localized source
interface: instruction family 2 selected the correct terminal code on 471/496
rows (94.96%), with 100% on premise families 0-6 and 59.68% on family 7. This
selection is disclosed development evidence; no LayerCake result informed it.

R72 freezes 2,100 new search prompts (300 per retained premise family), using
new five-digit nonce codes, the seven R71-perfect premise phrasings, and the
single measured robust instruction: do not stop after rule one; after both
transitions, select exactly the destination code. Prompts have zero exact
overlap with all prior catalogs and contain no real-world facts.

The pinned Phi weights score A/B/C candidate completions by mean conditional
log probability, with argmax selection independent of the expected evaluator.
The code and catalog are committed before source access. R72 records all 6,300
scalar scores, token counts, margins, hashes, runtime, hardware, and source
identity. It stores no hidden activations or full-vocabulary logit vectors.

Pass requires at least 1,995/2,100 correct selections (95%), at least 95% in
every retained premise family, and zero ties or non-finite scores. Only a pass
authorizes building a v3 segregated reasoning training artifact. R72 is
development acquisition evidence and cannot itself certify a host or moonshot.
