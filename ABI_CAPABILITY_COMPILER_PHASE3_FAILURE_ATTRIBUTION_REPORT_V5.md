The exact LayerCake checkpoint, repository commit, Phase 2 certificate, and
Phase 8 certificate all rehashed correctly. The native parent nevertheless
fails the broader ABI development prompt format. That is a measured scope gap,
not a regression and not proof of a representational ceiling.

The ABI payload signal is strong: C0 improves teacher-forced accuracy by 55.02
points and reduces NLL by 80.25% relative to no-payload C3. V11's prior
autonomous paired comparisons separately establish that semantic labels,
correct response pairing, and response supervision are causal.

The limiting mechanism is autonomous recovery. Across 166 eligible fixed
prompts, substituting one C0-generated wrong prefix token reduces immediate
next-token accuracy from 73.49% to 17.47%. Over the following 16 tokens, NLL
remains 1.77 times the clean-prefix value and accuracy remains 6.96 points
lower. This passes both preregistered prefix-sensitivity thresholds.

Therefore the next experiment belongs to the integration bridge: one bounded,
separately preregistered self-prefix-recovery successor. It must leave the
sealed LayerCake host unchanged. An ABI information-representation sweep or a
LayerCake rewrite is not supported by this evidence.

The verifier recomputed all identities and rejected six rehashed hostile
mutations. Phase 2 human ratings remain deferred, Phase 3 remains uncertified,
Phase 4 remains locked, and no ABI-over-LoRA-or-distillation claim is allowed.
