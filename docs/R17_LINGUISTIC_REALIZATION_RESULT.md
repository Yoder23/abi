# R17 bounded compositional English realization

Status: `PUBLIC_V1_SOURCE_INTERFACE_FAILED; PUBLIC_V2_REPAIR FROZEN`

R17 is the first post-R16 attempt to extract a generative linguistic rule
package instead of a fact table. It targets a registered surface-realization
family with 24 combinations of sentence mood, tense, polarity, and subject
number. Lexical content is supplied in the semantic frame, so the experiment
tests English form without importing specialist facts.

## Public interface v1

The protocol and implementation were frozen at commit `41aba49` before source
generation. Two attempts were aborted before any scientific row was written
because concurrent 7B-model review runs overcommitted the 16 GiB GPU; both are
preserved as `NOT_RUN` operational records. The first complete attempt is
`results/linguistic_realization_r17/public_v3/`.

The unchanged pinned Qwen2-7B-Instruct source failed its exact prerequisite:

| Gate | Result |
| --- | ---: |
| Extraction source outputs | 38/72 exact |
| Evaluation source outputs | 28/48 exact |
| Total source outputs | 66/120 exact |
| Rendered prompt bytes | 69,390 |
| Rendered prompt tokens | 15,496 |
| Generated tokens | 1,262 |
| Generated bytes | 4,609 |

Failures concentrated in interrogative mood, negative polarity, and some
future-tense rows. The v1 negative-question oracle also used an unnatural
uncontracted order (`Does not subject ...?`). ABI compilation, package
execution, and LayerCake were not invoked. This is therefore a source-interface
failure, not an ABI-compiler or LayerCake failure.

## Bounded v2 repair

`PUBLIC_PROTOCOL_V2.md` authorizes one repair driven by the observed failure:
explicit natural descriptions of question mood, polarity, future tense, and
the no-contraction constraint, plus the standard formal negative-question
order (`Does subject not ...?`). It changes no feature signature, record count,
lexical split, model revision, compiler algorithm, package representation,
control, or numerical gate.

If v2 does not pass all 120 exact source rows, the source-interface branch
closes. If it does, the already frozen physical compiler and causal controls
run before any hidden replication is authorized.

## Claim ceiling

No R17 claim is currently promoted. A later public and held-out pass would
still prove only bounded compositional surface realization for this registered
grammar family. Unrestricted English, autonomous discovery, production
LayerCake ingestion, global minimality, and superiority to LoRA or distillation
remain open.
