clean reconstruction, a repeated hostile replay, and a fresh blind review after
the R5 and R6 reviewers found real fail-open defects. Those failures remain
preserved as negative evidence.

The pass is deliberately bounded. It proves that four immutable capability
packages execute through one canonical conformance interface in three declared
host environments, with capability-blind physical certification and live
causal/removal controls. It does not prove arbitrary teacher-weight extraction,
human-quality fluent English, universal host support, or an advantage over LoRA
or distillation.
