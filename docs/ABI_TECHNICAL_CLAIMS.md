# ABI technical claims

Updated: 2026-08-30

## Claims supported by R7

- The published artifacts are standalone capability-runtime packages behind a
  canonical conformance boundary; they are not transformer-weight transplants.
- Four published immutable packages execute through the same canonical
  capability runtime/conformance interface in the declared LayerCake v25,
  Qwen2.5-0.5B, and Pythia-160M environments.
- Certification occurred in capability-blind filesystems. The exact 301,543
  row inventory scanned 11,681,888,205 reachable regular-file bytes and found
  no capability archive or success identifier.
- The locked matrix contains 5,043 rows. Live interventions contain 3,072 rows
  across 24 distinct condition processes; live isolation contains 2,100 rows
  with zero target successes.
- Package removal, adapter removal, host removal, zero/random/shuffled state,
  missing inputs, altered archives, stale receipts, and other registered hostile
  cases fail closed. Pre- and post-public hostile runs reject 19/19 mutations.
- A clean checkout reconstructed the frozen release only from its public
  manifest and assets, including Windows paths longer than 260 characters.
- A fresh blind Codex reviewer independently returned PASS for this bounded
  scope, including valid USTAR/V7 tar streams hidden at arbitrary prefixes.
