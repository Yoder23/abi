# Phase 3 oracle-fit ownership result

Status date: 2026-08-06

V20 and V21 are complete. They are deliberately development-contaminated,
permanently non-promotional controls.

After four direct exposures to every one of the 1,400 development teacher
pairs, the exact V11 C0 host plus 1,057,798-parameter bridge reached only
1,229/1,400 autonomous functional passes and produced 89 collapses. It failed
the 99% aggregate, 95%-per-capability, and zero-collapse oracle gates.

The read-only V21 likelihood split scored all 41,536 LayerCake target tokens.
Teacher-forced accuracy was 94.11% and mean NLL was 0.2631, missing the locked
95% and 0.20 thresholds. Instruction following was the largest fit failure at
68.47% token accuracy; conversation, email, and tone also remained below 95%.

Therefore the failure is not purely autonomous exposure bias. It is assigned
to bridge fit, optimization, or expressivity. The exact LayerCake repository,
checkpoint, and certificates still pass, so this is not a LayerCake regression;
nor does one failed bridge prove a fundamental host representational ceiling.

The scientific boundary is now clear: ABI extraction and labeling already
produce a causal payload signal, but further acquisition-data experiments would
be confounded by an insufficient integration bridge. The next bounded work must
increase or otherwise repair bridge expressivity, then repeat the contaminated
oracle upper bound and measure its added CPU inference cost. It may not borrow
the sealed host's speed result.

Phase 2 human ratings remain deferred, Phase 3 is uncertified, Phase 4 remains
locked, and ABI is not yet demonstrably stronger than LoRA or distillation.
