# Phase 3 hard-routed resilience result

Status date: 2026-08-07

V52 is complete and failed. Fourteen independently trained, body-only English
capability experts were selected by the already-qualified sparse router. The
bank completed 21,000 successful GPU updates in 472.45 seconds with zero
skipped AMP steps. It stored 58,439,920 generator parameters while activating
4,174,280 generator parameters and the 1,058,040-parameter router per request.

Autonomous quality reached 810/1,400 with 49 repetition collapses. Routing was
1,400/1,400 and generation had no runtime errors, but every discriminating
quality gate failed. The candidate trailed the frozen teacher by 30.50 points;
the paired 95% interval was [-32.79, -28.29] points.

The hard separation improved V50 by only 25 prompts and increased collapse by
13. Output inspection shows persistent substitution of acquisition-family
identifiers for held-out prompt identifiers. Therefore shared cross-capability
interference is not the primary remaining limit. The evidence supports one
materially distinct next representation question: Unicode-safe UTF-8-BPE
pointer supervision for prompt-entity copying. V52's remaining seeds and nearby
expert-bank variants are prohibited.

This is ABI acquisition/realization evidence. LayerCake was not modified, no
teacher or source block is present at inference, Phase 3 is not certified, and
Phase 4 remains locked.
